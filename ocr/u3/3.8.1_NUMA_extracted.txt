Non-uniform Memory Access
OPERATING SYSTEMS
In systems with multiple CPUs, a given CPU can access some sections of main memory faster than it can access others. 
These performance differences are caused by how CPUs and memory are interconnected in the system.
Systems in which memory access times vary significantly are known collectively as non-uniform memory access (NUMA) systems, and without exception, they are slower than systems in which memory and CPUs are located on the same motherboard
Managing which page frames are stored at which locations can significantly affect performance in NUMA systems. If we treat memory as uniform in such a system, CPUs may wait significantly longer for memory access than if we modify memory allocation algorithms to take NUMA into account.
NUMA Architecture
Components of a NUMA System
Processors (CPUs): Execute processes and access both local and remote memory.
Local Memory: Memory directly connected to a processor with the lowest access latency.
Remote Memory: Memory connected to another processor; accessed through the interconnect.
High-Speed Interconnect: Transfers data between processors and memory nodes.
Memory Controller: Handles memory requests and manages data transfer.
Operating System: Schedules processes and allocates memory to improve memory locality.

Memory locality
OPERATING SYSTEMS
Memory locality refers to the tendency of a program to access the same memory locations or nearby memory locations repeatedly over a short period of time. The principle of locality is the basis for efficient memory hierarchy design (registers, cache, RAM and virtual memory). Memory locality improves system performance by: 
    Reducing memory access time. 
    Increasing CPU cache hit rate. 
    Decreasing cache misses. 
    Improving virtual memory and paging efficiency. 
    Enhancing overall execution speed. 

Types of Memory locality
OPERATING SYSTEMS
1. Temporal Locality (Locality in Time)
If a memory location is accessed, it is likely to be accessed again in the near future.
Applications:
CPU cache stores recently accessed data. 
Frequently used instructions remain in the instruction cache. 
2. Spatial Locality (Locality in Space)
If a memory location is accessed, nearby memory locations are likely to be accessed soon.
Applications:
Cache loads an entire cache block (cache line), not just one memory location. 
Sequential file reading benefits from spatial locality.
