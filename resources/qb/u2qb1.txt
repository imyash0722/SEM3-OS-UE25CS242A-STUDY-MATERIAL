Lecture 1 – IPC: Shared Memory & Message Passing
================================================================================

1. Differentiate between shared memory and message passing with respect to
   communication mechanism and kernel involvement.

2. Why is synchronization necessary when multiple processes communicate using shared
   memory?

3. A multimedia application transfers large video frames between processes. Which IPC
   mechanism would you choose and why?

4. Differentiate between blocking and non-blocking message passing with suitable
   examples.

5. Explain the architecture of shared memory communication with a neat diagram.

6. Compare shared memory and message passing based on speed, synchronization, kernel
   involvement, and security.

7. Illustrate the sequence of communication between two processes using the send()
   and receive() primitives.

8. Explain how race conditions occur in shared memory communication and discuss
   suitable synchronization mechanisms to prevent them.

9. Explain the Producer-Consumer problem using the bounded buffer approach. What
   happens when the buffer is full and when it is empty?

10. Differentiate between direct and indirect communication in message passing. How
   does a mailbox-based system resolve the issue of multiple receivers?

11. Compare zero-capacity, bounded-capacity, and unbounded-capacity buffering in
   message passing. In which case must the sender always wait?

12. A weather forecasting system consists of multiple computational processes that
   frequently exchange large matrices. Analyze whether shared memory or message
   passing is more appropriate.

13. Design an IPC architecture for an online banking system where multiple
   independent processes exchange transaction information. Justify the choice of IPC
   mechanism considering performance, security, and reliability.

14. Compare shared memory and message passing in terms of implementation complexity,
   scalability, synchronization overhead, fault isolation, security, and practical
   applications.

15. Design a producer-consumer communication framework using shared memory. Explain
   how semaphores or mutexes can be used to eliminate race conditions.

16. What are the reasons for process cooperation? List the advantages of cooperating
   processes.

17. Explain what a rendezvous is in the context of message passing synchronization.

18. Explain how a message-passing system handles the Producer-Consumer problem
   compared to the shared memory approach. Which approach is simpler to implement?
