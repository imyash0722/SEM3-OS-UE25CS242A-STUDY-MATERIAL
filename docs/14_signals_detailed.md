## 14.1 Signal Fundamentals

### What is a Signal?

A **signal** is a software interrupt — a notification to a process that an event has occurred.

```
┌─────────────────────────────────────────────────────────────┐
│                    SIGNAL LIFECYCLE                          │
│                                                              │
│  GENERATION → DELIVERY → HANDLING                           │
│       │            │            │                            │
│       ▼            ▼            ▼                            │
│  Event      Kernel marks    Process executes                │
│  occurs     signal pending  handler (or default)            │
└─────────────────────────────────────────────────────────────┘
```

### Generation Sources

| Source | Examples |
|--------|----------|
| **Hardware exceptions** | Division by zero (SIGFPE), invalid memory (SIGSEGV), illegal instruction (SIGILL) |
| **Terminal** | Ctrl+C (SIGINT), Ctrl+Z (SIGTSTP), Ctrl+\ (SIGQUIT) |
| **Timers** | alarm() (SIGALRM), setitimer() |
| **Process events** | Child exit (SIGCHLD), pipe broken (SIGPIPE) |
| **Explicit** | kill(), raise(), sigqueue() |

---

## 14.2 Signal Classification

### Synchronous vs Asynchronous

| Type | Generated By | Delivered To |
|------|--------------|--------------|
| **Synchronous** | Current instruction (fault) | The **faulting thread** |
| **Asynchronous** | External event | Process or any thread not blocking it |

| Signal | Type | Typical Cause |
|--------|------|---------------|
| SIGSEGV | Synchronous | Invalid memory access |
| SIGFPE | Synchronous | Division by zero, FP exception |
| SIGILL | Synchronous | Illegal instruction |
| SIGBUS | Synchronous | Bus error (misaligned access) |
| SIGINT | Asynchronous | Ctrl+C |
| SIGALRM | Asynchronous | Timer expiration |
| SIGCHLD | Asynchronous | Child terminated |
| SIGPIPE | Asynchronous | Write to closed pipe |
| SIGUSR1/2 | Asynchronous | User-defined |

---

## 14.3 Signal Dispositions (Actions)

Every signal has a **disposition** (what happens when delivered):

| Disposition | Meaning |
|-------------|---------|
| **Default** | Kernel-defined action (Term, Core, Ign, Stop, Cont) |
| **Ignore** | Signal discarded (SIG_IGN) |
| **Catch** | User-defined handler function |

### Default Actions

| Signal | Default Action | Description |
|--------|----------------|-------------|
| SIGINT | Terminate | Terminal interrupt |
| SIGTERM | Terminate | Termination request |
| SIGKILL | **Terminate** | **Uncatchable, unignorable** |
| SIGSTOP | **Stop** | **Uncatchable, unignorable** |
| SIGQUIT | Core dump | Quit (Ctrl+\) |
| SIGSEGV | Core dump | Segmentation fault |
| SIGFPE | Core dump | Arithmetic exception |
| SIGCHLD | Ignore | Child stopped/terminated |
| SIGPIPE | Terminate | Broken pipe |
| SIGALRM | Terminate | Alarm clock |

> **Critical**: SIGKILL (9) and SIGSTOP (17/19/23) **cannot be caught, blocked, or ignored**.

## 14.4 Signal Handling APIs

### Legacy: signal()

```c
#include <signal.h>

// Simple but limited
void (*signal(int sig, void (*handler)(int)))(int);

// Example
void handler(int sig) {
    printf("Caught signal %d\n", sig);
}

signal(SIGINT, handler);  // Set handler
signal(SIGINT, SIG_DFL);  // Restore default
signal(SIGINT, SIG_IGN);  // Ignore
```

**Limitations**:
- Not portable (System V vs BSD semantics)
- Handler reset on delivery (System V)
- No signal masking during handler

---

### Modern: sigaction()

```c
#include <signal.h>

struct sigaction {
    void     (*sa_handler)(int);      // Handler (or SIG_DFL/SIG_IGN)
    void     (*sa_sigaction)(int, siginfo_t *, void *); // With info
    sigset_t sa_mask;                 // Signals blocked during handler
    int      sa_flags;                // SA_RESTART, SA_SIGINFO, etc.
    void     (*sa_restorer)(void);    // Obsolete
};

int sigaction(int signum, const struct sigaction *act, struct sigaction *oldact);
```

### Complete Example

```c
#include <signal.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>

volatile sig_atomic_t got_signal = 0;

void handler(int sig, siginfo_t *info, void *ucontext) {
    // Async-signal-safe: only use safe functions!
    got_signal = 1;
    printf("Caught signal %d from PID %d\n", sig, info->si_pid);
}

int main() {
    struct sigaction sa;
    
    // Zero initialize
    memset(&sa, 0, sizeof(sa));
    
    // Use sa_sigaction (gets siginfo_t)
    sa.sa_sigaction = handler;
    
    // Block SIGTERM during handler
    sigemptyset(&sa.sa_mask);
    sigaddset(&sa.sa_mask, SIGTERM);
    
    // Flags: SA_SIGINFO = use sa_sigaction, SA_RESTART = restart syscalls
    sa.sa_flags = SA_SIGINFO | SA_RESTART;
    
    if (sigaction(SIGINT, &sa, NULL) == -1) {
        perror("sigaction");
        exit(1);
    }
    
    printf("Waiting for SIGINT (Ctrl+C)...\n");
    while (!got_signal) pause();  // Wait for signal
    
    printf("Signal received, exiting cleanly\n");
    return 0;
}
```

### Common sa_flags

| Flag | Effect |
|------|--------|
| `SA_RESTART` | Restart interrupted syscalls (read, write, etc.) |
| `SA_SIGINFO` | Use `sa_sigaction` (3 args) instead of `sa_handler` (1 arg) |
| `SA_NOCLDSTOP` | Don't get SIGCHLD when child stops |
| `SA_NOCLDWAIT` | Don't create zombies (auto-reap) |
| `SA_NODEFER` | Don't block signal during handler |
| `SA_RESETHAND` | Reset to SIG_DFL after handler runs (one-shot) |
| `SA_ONSTACK` | Use alternate signal stack |

## 14.5 Signal Sets & Blocking

```c
#include <signal.h>

sigset_t set;
sigemptyset(&set);      // Empty set
sigfillset(&set);       // All signals
sigaddset(&set, SIGINT); // Add signal
sigdelset(&set, SIGTERM); // Remove signal
sigismember(&set, SIGINT); // Test membership

// Block signals
sigprocmask(SIG_BLOCK, &set, NULL);

// Unblock signals
sigprocmask(SIG_UNBLOCK, &set, NULL);

// Replace mask
sigprocmask(SIG_SETMASK, &set, &oldset);

// Get pending signals
sigpending(&set);
```

### Typical Pattern: Temporarily Block Signal

```c
sigset_t block_set, old_set;
sigemptyset(&block_set);
sigaddset(&block_set, SIGINT);

// Block SIGINT
sigprocmask(SIG_BLOCK, &block_set, &old_set);

// Critical section (no SIGINT interruption)
do_critical_work();

// Restore old mask (unblocks SIGINT)
sigprocmask(SIG_SETMASK, &old_set, NULL);
```

## 14.6 Async-Signal-Safe Functions

**Only these can be safely called from a signal handler:**

| Category | Functions |
|----------|-----------|
| I/O | `write`, `read`, `open`, `close`, `lseek` |
| Process | `fork`, `exec*`, `_exit`, `exit`, `kill`, `raise`, `alarm` |
| Signal | `sigaction`, `sigprocmask`, `sigpending`, `sigsuspend`, `sigwait` |
| Time | `sleep`, `nanosleep`, `clock_gettime` |
| Memory | **NONE** (malloc/free NOT safe!) |

**NEVER use in handler**: `printf`, `malloc`, `free`, `pthread_mutex_lock`, `strcpy`, `strtok`, etc.

### Safe Handler Pattern

```c
volatile sig_atomic_t flag = 0;  // Atomic flag

void handler(int sig) {
    flag = 1;  // Only set atomic variable
}

int main() {
    signal(SIGINT, handler);
    while (!flag) {
        // Do work
    }
    // Handle signal in main context (can use printf, malloc, etc.)
    printf("Signal received!\n");
}
```

## 14.7 Advanced Signal Patterns

### 1. Timeout with alarm()

```c
void timeout_handler(int sig) {
    // Handle timeout
}

void do_with_timeout(int seconds) {
    signal(SIGALRM, timeout_handler);
    alarm(seconds);  // SIGALRM in 'seconds'
    
    // Do work that might hang
    int result = slow_operation();
    
    alarm(0);  // Cancel alarm
    return result;
}
```

### 2. Ignore SIGPIPE (Common in Network Code)

```c
signal(SIGPIPE, SIG_IGN);  // Prevent crash on broken pipe

// Or better:
struct sigaction sa = { .sa_handler = SIG_IGN };
sigaction(SIGPIPE, &sa, NULL);
```

### 3. Wait for Signal (sigsuspend)

```c
sigset_t mask;
sigemptyset(&mask);
sigaddset(&mask, SIGUSR1);

// Wait for SIGUSR1
sigsuspend(&mask);  // Atomically unmask and wait
```

### 4. Signal + Threads

```c
// Each thread has its own signal mask
pthread_sigmask(SIG_BLOCK, &set, &oldset);  // Block in this thread

// Send signal to specific thread
pthread_kill(thread_id, SIGUSR1);

// Dedicated signal handling thread
void *signal_thread(void *arg) {
    sigset_t set;
    sigfillset(&set);
    pthread_sigmask(SIG_BLOCK, &set, NULL);  // Block all in this thread
    
    while (1) {
        int sig;
        sigwait(&set, &sig);  // Wait for any signal
        handle_signal(sig);
    }
}
```

## 14.8 Complete Signal Demo Program

```c
/*
 * File: signals_demo.c
 * Comprehensive signal handling demonstration
 * Compile: gcc -o signals_demo signals_demo.c
 */

#include <signal.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/wait.h>

volatile sig_atomic_t sigint_count = 0;
volatile sig_atomic_t sigusr1_count = 0;
volatile sig_atomic_t child_done = 0;

void sigint_handler(int sig) {
    sigint_count++;
    printf("\n[SIGINT] Count: %d\n", sigint_count);
    if (sigint_count >= 3) {
        printf("  Three SIGINTs - exiting\n");
        _exit(0);
    }
}

void sigusr1_handler(int sig) {
    sigusr1_count++;
    printf("[SIGUSR1] Count: %d\n", sigusr1_count);
}

void sigchld_handler(int sig) {
    int status;
    pid_t pid;
    while ((pid = waitpid(-1, &status, WNOHANG)) > 0) {
        if (WIFEXITED(status)) {
            printf("[SIGCHLD] Child %d exited with code %d\n", pid, WEXITSTATUS(status));
        } else if (WIFSIGNALED(status)) {
            printf("[SIGCHLD] Child %d killed by signal %d\n", pid, WTERMSIG(status));
        }
        child_done = 1;
    }
}

void setup_handlers() {
    struct sigaction sa = {0};
    
    // SIGINT: count, exit after 3
    sa.sa_handler = sigint_handler;
    sa.sa_flags = SA_RESTART;
    sigaction(SIGINT, &sa, NULL);
    
    // SIGUSR1: count
    sa.sa_handler = sigusr1_handler;
    sigaction(SIGUSR1, &sa, NULL);
    
    // SIGCHLD: reap children
    sa.sa_handler = sigchld_handler;
    sa.sa_flags = SA_NOCLDSTOP | SA_RESTART;
    sigaction(SIGCHLD, &sa, NULL);
}

void child_process() {
    printf("[CHILD %d] Started, sleeping 2s\n", getpid());
    sleep(2);
    printf("[CHILD %d] Exiting with code 42\n", getpid());
    exit(42);
}

int main() {
    setup_handlers();
    
    printf("PID: %d\n", getpid());
    printf("Try: kill -SIGINT %d  (Ctrl+C)\n", getpid());
    printf("Try: kill -SIGUSR1 %d\n", getpid());
    printf("Try: kill -SIGCHLD %d (after child exits)\n", getpid());
    
    // Fork a child
    pid_t pid = fork();
    if (pid == 0) {
        child_process();
    }
    
    printf("\nParent waiting for signals...\n");
    
    // Main loop
    while (1) {
        if (sigint_count >= 3) break;
        if (child_done) break;
        pause();  // Wait for signal
    }
    
    printf("Exiting\n");
    return 0;
}
```

## 14.9 Windows Alternative: APCs

Windows doesn't have POSIX signals. Uses **Asynchronous Procedure Calls (APCs)**:

| POSIX Signal | Windows APC |
|--------------|-------------|
| Delivered to process | Delivered to **specific thread** |
| Handler runs in thread context | Callback runs in thread's alertable wait |
| `kill(pid, sig)` | `QueueUserAPC(callback, thread, data)` |

```c
// Windows APC example
DWORD WINAPI MyAPC(ULONG_PTR data) {
    printf("APC executed with data: %lu\n", data);
}

// Queue APC to thread
QueueUserAPC(MyAPC, thread_handle, 42);

// Thread must enter alertable wait:
SleepEx(INFINITE, TRUE);  // TRUE = alertable
WaitForSingleObjectEx(handle, INFINITE, TRUE);
```

## 14.10 Complete Exam-Focused Summary

| Concept | Key Points |
|---------|------------|
| **Signal lifecycle** | Generation → Delivery → Handling |
| **Synchronous** | Internal fault (SIGSEGV, SIGFPE) → delivered to faulting thread |
| **Asynchronous** | External (SIGINT, SIGALRM) → delivered to process/any thread |
| **Cannot catch/block** | SIGKILL (9), SIGSTOP |
| **sigaction() > signal()** | Portable, masking, flags, siginfo_t |
| **SA_RESTART** | Restart interrupted syscalls |
| **SA_SIGINFO** | Use 3-arg handler (gets siginfo_t) |
| **Async-signal-safe** | Only: write, fork, exec, _exit, kill, sigaction, etc. |
| **sigprocmask** | Block/unblock signals in thread |
| **sigsuspend** | Atomically wait for signal |
| **Windows** | Uses APCs, not signals |

## 14.11 Common Pitfalls

| Pitfall | Wrong | Correct |
|---------|-------|---------|
| printf in handler | `printf("caught\n");` | Set atomic flag, handle in main |
| malloc in handler | `malloc(100);` | Pre-allocate, or avoid |
| mutex in handler | `pthread_mutex_lock(&m);` | Never block in handler |
| longjmp from handler | `longjmp(buf, 1);` | Use siglongjmp if needed |
| signal() portability | `signal(SIGINT, h);` | Use sigaction() |
| Ignoring SIGCHLD | `signal(SIGCHLD, SIG_IGN);` | Use SA_NOCLDWAIT |
| Missing SA_RESTART | Interrupted syscalls fail | Add SA_RESTART |
