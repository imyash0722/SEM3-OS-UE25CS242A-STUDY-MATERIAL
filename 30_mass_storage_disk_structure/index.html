Topic 30: Mass Storage Structure — Disk Structure & SSD¶

Source: Lecture 4.6 (Unit 4) + Textbook Ch. 12 (Silberschatz Ch. 12, Stallings Ch. 13)

30.1 Magnetic Disk Structure¶

Physical Organization¶

Component Description
Platter Flat circular disk (1.8"-3.5" diameter); both sides coated with magnetic material
Track Concentric circle on platter surface
Sector Smallest addressable unit (typically 512B or 4KB)
Cylinder Set of tracks at same radius across all platters
Head Read/write element on actuator arm
Arm Moves all heads together as a unit

Disk Geometry¶

Platter (top & bottom surfaces)
    ↓
Track (concentric circle)
    ↓
Sector (smallest addressable unit, 512B/4KB)
    ↓
Cylinder = all tracks at same radius across platters

Disk Addressing (CHS)¶

Cylinder (C) = Arm position
Head (H)     = Platter surface (0 or 1 per platter)
Sector (S)   = Sector number within track

LBA = (C × Heads × Sectors/Track) + (H × Sectors/Track) + S

30.2 Disk Performance Metrics¶

Disk Latency Components¶

Disk Latency = Seek Time + Rotational Latency + Transfer Time
Component Description Typical Value
Seek Time Move arm to target cylinder 3-10 ms (avg)
Rotational Latency Wait for sector to rotate under head 0.5 × Rotation Period (2-4 ms at 7200 RPM)
Transfer Time Data transfer rate 50-200 MB/s

Total Latency Formula¶

Disk Latency = Seek Time + Rotational Latency + (Bytes / Transfer Rate)

Disk Speed¶

  • Rotation: 5,400 - 15,000 RPM (typically 7,200 RPM)
  • Rotation Period: 8.33 ms (7200 RPM)
  • Average Rotational Latency: 4.17 ms (half rotation)

30.3 Disk Operation¶

Moving-Head Mechanism¶

  • Actuator Arm moves all heads together
  • Voice Coil Motor or Stepper Motor
  • Heads fly on air bearing (nanometers above surface)

Head Crash¶

  • Head contacts platter surface
  • Catastrophic: Data loss, physical damage
  • Non-recoverable in most cases

Air Bearing¶

  • Head flies on air cushion (nanometers above surface)
  • Generated by platter rotation
  • Power loss → heads park automatically

30.4 Disk Controller & Interface¶

I/O Bus Types¶

Bus Speed Use Case
EIDE/ATA Legacy Older systems
SATA 1.5-6 Gbps Consumer HDD/SSD
SAS 12-24 Gbps Enterprise
Fiber Channel 16-128 Gbps SAN
NVMe PCIe 3.0/4.0 High-performance SSD

Controller Hierarchy¶

CPU → System Bus → Host Controller → I/O Bus → Disk Controller → Disk

30.4 Solid-State Drives (SSD)¶

SSD Characteristics¶

Property HDD SSD
Moving Parts Yes No
Seek Time 3-10 ms None (0)
Rotational Latency 2-4 ms None (0)
Access Time ~10 ms ~0.1 ms
Noise Mechanical Silent
Shock Resistance Low High
Cost/GB Low Higher
Lifespan Unlimited writes Limited write cycles

SSD Interfaces¶

Interface Speed Notes
SATA 6 Gbps Legacy compatibility
NVMe PCIe 3.0/4.0/5.0 High performance, direct PCIe
U.2/U.3 Enterprise Hot-plug capable

30.5 Magnetic Tape¶

Characteristics¶

Property Value
Access Time Very slow
Random Access ~1000× slower than disk
Capacity Very high (PB per cartridge)
Cost/GB Lowest
Portability High (removable)

Use Cases¶

Use Case Description
Backup Full system backups
Archival Infrequently accessed data
Transfer Large data transfer between sites
Compliance Legal/regulatory retention

30.5 Magnetic Tape vs Disk¶

Aspect Disk Tape
Access Random Sequential
Latency ms seconds-minutes
Throughput 100-200 MB/s 300-800 MB/s (LTO)
Cost/GB Higher Lowest
Durability 3-5 years 30+ years

30.6 Key Takeaways¶

  1. Disk Structure: Platters → Tracks → Sectors → Cylinders
  2. Disk Latency = Seek + Rotational Latency + Transfer
  3. Seek Time = Arm movement to cylinder (3-10 ms)
  4. Rotational Latency = 0.5 × rotation period (2-4 ms at 7200 RPM)
  5. SSD = No seek/rotational latency; NAND flash; limited write cycles
  6. Tape = Sequential only; backup/archival; high capacity, low cost
  7. Interfaces: SATA, SAS, NVMe, Fiber Channel

30.7 Exam-Relevant MCQ Patterns¶

Question Answer
Disk latency formula Seek + Rotational + Transfer
Rotational latency (7200 RPM) 4.17 ms (half of 8.33ms rotation)
Cylinder Tracks at same radius across platters

Seek time Arm movement to cylinder
Rotational latency Time for sector to rotate under head
NVMe PCIe-based SSD interface
